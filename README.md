# 🎓 Металлург — Личная Энциклопедия

Добро пожаловать в интерактивную базу знаний! Этот проект создан для удобной и структурированной подготовки к зачетам и экзаменам по специальности **22.02.10 «Металлургия цветных металлов»**.

Приложение работает полностью офлайн (без интернета), не требует установки серверов и баз данных. Всё, что нужно — это браузер.

---

## ✨ Возможности

- **📚 Удобная структура:** Все материалы разбиты по курсам, предметам и типам файлов.
- **🃏 Интерактивные карточки:** Для заучивания вопросов и ответов (режим переворачивания).
- **📖 Лекции и шпаргалки:** Сплошной текст для чтения и быстрого повторения перед зачетом.
- **🎯 Тесты с вариантами ответов:** Проверка знаний с мгновенной обратной связью и подсчетом баллов.
- **📄 Умные файлы:** PDF-файлы открываются прямо в браузере, а исходники (Word/PPT) можно скачать одной кнопкой.

## 📂 Структура проекта

Проект организован так, чтобы в нем было легко ориентироваться:

```text
metallurg/
│
├── index.html              # Главное меню (хаб), который вы открываете
├── README.md               # Этот файл с описанием
│
├── apps/                   # Интерактивные приложения
│   ├── omp.html            # Карточки и тесты по ОМП
│   └── cm.html             # Карточки и тесты по ЦМ
│
└── docs/                   # Учебные материалы
    ├── omp/                # Документы по предмету ОМП
    │   ├── pdf/            # Файлы для чтения в браузере
    │   └── word/           # Исходники для скачивания
    │
    └── cm/                 # Документы по предмету ЦМ
        ├── pdf/
        └── word/


        🚀 Как пользоваться
Скачайте или склонируйте папку metallurg на свой компьютер или телефон.

Дважды кликните по файлу index.html. Он откроется в любом современном браузере (Chrome, Safari, Яндекс.Браузер).

Выбирайте курс, предмет и нужный материал.

Для установки на телефон как приложение (PWA) — разместите проект на бесплатном хостинге (например, GitHub Pages) и выберите «Добавить на главный экран» в браузере.

🛠️ Как добавить новый материал (Инструкция для себя)
Если появились новые лекции или вопросы, вот алгоритм действий:

Конвертируйте файл Word (.docx) или Презентацию (.ppt) в формат PDF. Это нужно, чтобы браузер мог открыть их для чтения прямо на сайте.

Положите файлы в нужные папки:

PDF — в docs/название_предмета/pdf/

Word/PPT — в docs/название_предмета/word/

Откройте index.html любым текстовым редактором (Блокнот, Notepad++, VS Code).

Найдите в самом низу блок <script>, а в нем — массив data.files.

Добавьте новую строчку по аналогии с другими:

javascript
{ name: "Название лекции", file_pdf: "docs/omp/pdf/Имя_файла.pdf", file_word: "docs/omp/word/Имя_файла.docx", icon: "📄" },
Сохраните index.html и обновите страницу в браузере.

💻 Технологии
HTML5 — семантическая разметка.

CSS3 — адаптивный дизайн, Glassmorphism (стеклянные карточки), анимации.

Vanilla JavaScript (ES6) — вся логика навигации, рендеринга списков и работы интерактивных приложений (без сторонних библиотек и фреймворков).
